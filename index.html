Do LLM judges rank partially correct code fixes the way hidden tests do?

Preregistered. Pilot complete. Under preparation for peer review.

Blind peer matrix

Pools of 8 to 10 language models answered the same question and then scored each other's answers with model names withheld: 286 evaluations and 22,252 usable scored judgments. My own audit on 16 August 2026 found that 178 of the 500 code answers end inside an unclosed code block, and that 291 of the judgments counted as usable gave a positive score to an answer that was stored empty.

Completed project. Not being pursued for publication.

Code and data: github.com/themultivac/multivac-evaluation

Anecdote, not a result: on one coding question, two valid LLM judgments both gave an answer 10.0, and when its fix was run it oversold stock in 25 of 25 concurrency trials, while the two lower ranked fixes oversold in none.
